# Skills

My personal agent skills for **Claude Code** and **Codex** — small, focused workflows I use in day-to-day in my projects.

## Installation

<details>
<summary><strong>Claude Code</strong></summary>

```bash
claude plugin marketplace add xmichsenx/skills
claude plugin install xmichsenx-skills@xmichsenx
```

</details>

<details>
<summary><strong>Codex</strong></summary>

```bash
codex plugin marketplace add xmichsenx/skills
codex plugin add xmichsenx-skills@xmichsenx
```

</details>
